## User

UI mockup design sheet for an 'Agent Chatroom' interface — a multi-agent conversation dashboard where AI agents communicate with one another in real time and a human user can monitor progress. The interface includes: a central chat thread panel showing labeled agent messages with distinct avatar icons and color-coded name tags, a sidebar listing active agents with status indicators (idle, thinking, working), a progress tracker panel showing task completion steps or a kanban-style pipeline, a user input bar at the bottom for human intervention or commands, and a collapsible agent detail pane showing each agent's current subtask and output log. Visual style: clean modern SaaS UI, flat design with subtle depth, dark mode color scheme with electric blue and violet accent colors, crisp sans-serif typography, high-fidelity wireframe aesthetic. Composition: multi-panel desktop layout, top-down orthographic view, full-width 16:9 aspect ratio.
